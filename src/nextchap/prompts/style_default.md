# Style guide

Edit this file to steer every generated chapter. It is sent with each writing request.

- Match the voice, tense and point of view of the existing chapters.
- Keep chapter openings in-scene; no recaps.
- Dialogue: use the punctuation conventions of the source text.
- Keep each character's own vocabulary; nobody explains their own subtext.
- Vary sentence length; never three sentences in a row of similar length.
- Let the prose be as irregular as the source text: fragments, sentences opening with And or But, comma splices at speed, interruptions in dialogue. No typos.
- Avoid these overused phrases: "a testament to", "sent shivers down", "the air was thick with", "little did they know", "only time would tell", "unbeknownst to them", "turns out", "furthermore", "moreover".
